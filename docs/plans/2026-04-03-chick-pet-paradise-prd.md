# 小鸡宠物乐园 — 产品需求文档 (PRD)

## 1. 项目概览

**项目名称：** 小鸡宠物乐园

**产品定位：** 一款卡通手绘风的网页养成 + 放置游戏，适合小朋友和所有喜欢治愈系游戏的玩家。

**应用形式：** 网页应用（浏览器打开即玩，方便分享）

**技术栈：** React + Pixi.js + TypeScript

**画面风格：** 卡通手绘风 — 圆润可爱，色彩鲜艳

---

## 2. 核心玩法

### 2.1 玩法优先级

| 优先级 | 玩法 | 说明 |
|--------|------|------|
| P0 | 养成 | 孵蛋、喂养、看小鸡成长，核心基础体验 |
| P0 | 放置 | 小鸡在乐园自由活动，追逐、啄食、打盹，主打治愈 |
| P1 | 经营 | 收鸡蛋、赚金币、扩建乐园（后续版本加入） |

### 2.2 核心体验

- 从一颗蛋开始，孵化、喂养、看小鸡成长
- 小鸡在乐园里自由活动，追逐、啄食、打盹，主打治愈
- 多品种收集系统，包含隐藏稀有品种，激发收集欲
- 到处可点击，丰富的动画反馈，适合小朋友

---

## 3. 小鸡生命周期

### 3.1 成长阶段

| 阶段 | 名称 | 说明 |
|------|------|------|
| 1 | 蛋 | 带有花纹的蛋，偶尔会晃动 |
| 2 | 破壳 | 蛋壳出现裂缝，小鸡慢慢钻出来 |
| 3 | 毛绒小鸡 | 毛茸茸的小鸡仔，动作笨拙可爱 |
| 4 | 少年鸡 | 体型变大，羽毛渐丰，更活泼好动 |
| 5 | 成年鸡 | 完全长大，品种特征完全显现 |

每个阶段外观和行为都不同。

### 3.2 品种系统

| 稀有度 | 品种 | 示例 |
|--------|------|------|
| 普通 | 基础色系 | 白鸡、黄鸡、棕鸡 |
| 特殊 | 花纹/彩色 | 斑点鸡、条纹鸡、彩色鸡 |
| 隐藏稀有 | 特殊品种 | 金鸡、彩虹鸡等 |

---

## 4. 互动系统

### 4.1 互动方式优先级

| 优先级 | 方式 | 说明 |
|--------|------|------|
| P0 | 点击 + 动画反馈 | 到处点击都有惊喜反馈，最直觉的操作 |
| P1 | 手势互动 | 滑动抚摸、长按抱起等 |
| P2 | 声音互动 | 对麦克风发声，小鸡会围过来 |

### 4.2 逗玩互动

- 鼠标移动时，附近的小鸡会好奇地追着光标跑
- 点击小鸡：它会跳起来"叽叽"叫，头顶冒爱心
- 长按小鸡：抱起来，它会蹭你，放下时恋恋不舍
- 在地面快速划动：小鸡们会兴奋地追过来

### 4.3 迷你小游戏

| 游戏 | 玩法 |
|------|------|
| 丢球捡回 | 扔出一个小球，小鸡跑去叼回来，不同品种速度不同 |
| 躲猫猫 | 小鸡藏在灌木/花丛后面，点击找出来 |
| 赛跑 | 选一只小鸡参赛，给它加油（疯狂点击），跑赢了得奖励 |

### 4.4 情感系统

- 每只小鸡有心情值：开心 → 普通 → 无聊 → 生气
- 互动、喂食、玩游戏会提升心情
- 长时间不理它会掉心情，生气的小鸡会背对你、不吃东西
- 心情好的小鸡动作更活泼，会主动跑来找你

### 4.5 环境点击反馈

| 点击位置 | 效果 |
|----------|------|
| 地面 | 长出小花小草 |
| 天空 | 飘过云朵或蝴蝶 |
| 水池 | 溅起水花，附近小鸡跑过去玩水 |

---

## 5. 养成系统

### 5.1 日常照料

- **喂食：** 给小鸡撒食物（谷物、虫子、特殊食物影响成长方向）
- **喝水：** 保持水槽有水
- **清洁：** 打扫乐园卫生
- **陪玩：** 通过互动系统跟小鸡玩耍

### 5.2 成长机制

- 小鸡通过进食和时间推移逐渐成长
- 不同食物/互动可能影响最终品种
- 照料得当的小鸡成长更快、更健康

---

## 6. 乐园环境

### 6.1 场景元素

- 草地、花丛、灌木
- 水池/小溪
- 鸡舍（小鸡的家）
- 围栏
- 天空（日夜变化）

### 6.2 放置行为（小鸡 AI）

小鸡在乐园中会自主进行以下行为：
- 四处走动、啄食地面
- 追逐其他小鸡
- 在水池边喝水/玩水
- 找个角落打盹睡觉
- 结伴活动

---

## 7. 后续规划（P1）

以下功能在核心体验稳定后逐步加入：

- **经营系统：** 收集鸡蛋、赚金币、扩建乐园
- **商店系统：** 购买装饰物、特殊食物、新蛋
- **手势互动：** 滑动抚摸、拖拽物品
- **声音互动：** 麦克风互动
- **成就系统：** 收集所有品种、达成特定目标

---

## 8. 技术方案

| 项目 | 选型 |
|------|------|
| 框架 | React 18+ |
| 渲染引擎 | Pixi.js（2D 渲染、精灵动画、粒子特效） |
| 语言 | TypeScript |
| 状态管理 | Zustand 或 React Context |
| 构建工具 | Vite |
| 部署 | 静态网页，支持任意托管平台 |
